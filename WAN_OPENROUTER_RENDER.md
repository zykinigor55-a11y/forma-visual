# Подключение Wan 2.6 Free к ДОМ.РЕНДЕР (Render)

Сервис: https://dom-render-nanobanana.onrender.com

Код работает в ветке `dom-render-nanobanana`, Node.js 20+, `node server.mjs`. **Не смешивать с Next.js-веткой main**.

## Переменные окружения Render

В Render → dom-render-nanobanana → Environment добавьте:

```text
OPENROUTER_API_KEY=<секретный ключ из https://openrouter.ai/settings/keys>
WAN_VIDEO_ENABLED=true
WAN_PUBLIC_ORIGIN=https://dom-render-nanobanana.onrender.com
WAN_DAILY_LIMIT=3
```

Никогда не публикуйте значение ключа в GitHub, браузере, HTML или чате. Используйте только Environment (секрет Render).
Публичную генерацию платных моделей не включать: backend вызывает исключительно `alibaba/wan-2.6:free`; проверяет цену и поддержку `first_frame` в `GET /api/v1/videos/models`. При отсутствии бесплатной модели не запускает ничего.

## Использование

Откройте сайт → «Анимация» → выберите кинокамеру, объектив, движение и оптический фильтр → ниже блок «Генерация видео Wan 2.6». Можно взять исходник из текущего предпросмотра либо вручную загрузить JPG/PNG/WebP до 8 МБ. Выберите 5 или 10 секунд и нажмите «Создать видео». Через отдельный серверный маршрут опрашивается статус; готовый MP4 скачивается кнопкой.

## API

- `GET /api/wan/status` — ключ настроен / есть ли бесплатная модель в текущем каталоге.
- `POST /api/wan/generate` — отправка видео: `{ image: dataURL, prompt, duration, ratio }`.
- `GET /api/wan/job?id=<uuid>` — статус генерации.
- `GET /api/wan/download?id=<uuid>` — скачивание MP4 после завершения.
- `GET /api/wan/frame?id=<uuid>` — временный прямой кадр для провайдера по случайному секретному URL (TTL 2 часа).

## Ограничения тестовой версии

На текущем Render сервере отсутствуют личные учётные записи и постоянная БД заданий: идентификаторы генераций и временные изображения лежат **в памяти Node процесса**. При перезапуске Render они теряются. Общий дневной лимит также хранится в памяти (по умолчанию 3 попытки). Это защитный тестовый лимит, не система коммерческих квот. Для многопользовательского запуска нужны аккаунты, постоянная БД и ограничение по пользователю/IP, внешний bucket для исходников, автоматическая очистка временных файлов и антиабьюз.

Передаваемые кадры проходят через OpenRouter и его провайдеров: не загружайте конфиденциальные материалы без согласия заказчика.

**Реальная Wan-генерация не проверялась без ключа пользователя.** Тесты backend выполнены с эмуляцией ответа API. Бесплатная модель не гарантированно доступна в конкретный момент, несмотря на страницу с нулевой ценой.
