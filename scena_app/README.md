# СЦЕНА v1.4 — личное караоке

Премиальное мобильное караоке для личного пользования: загрузка своих MP3/WAV/M4A, четыре аудиореактивных эквалайзера, экран песен, студия, записи, кнопка преобразования в караоке и настройки облачного ИИ.

- `index.html` — готовый браузерный интерфейс (UI)
- `android/` — Android / Android TV исходники
- `../scena_cloud/` — FastAPI + Demucs + Faster-Whisper (сервер)
- `.github/workflows/scena-build-apk.yml` — автоматическая сборка APK в GitHub Actions

**Облачный сервер**: https://scena-karaoke-cloud.onrender.com

**Установка APK**: открыть Actions → Build SCENA Android APK → Run workflow (ветка scena-cloud-20261112) → скачать артефакт SCENA-Android-v1.4-debug-apk после успешной сборки.

**Ограничения**: бесплатный Render 512 МБ может не выполнить ИИ-разделение из-за нехватки RAM; наличие кнопки не означает готовность моделей. Секретные коды доступа в GitHub не сохраняются. Для работы с чужой музыкой учитывайте условия её использования.

**Просмотр в браузере**: рекомендуется открывать интерфейс и API на одном домене (`https://scena-karaoke-cloud.onrender.com/app`), иначе встроенный просмотрщик ChatGPT может блокировать внешние запросы.
