# PLUX V12.4 — Motion System

Обновление анимаций на основе **PLUX V12.3 Optical Glass**. Дизайн утверждённых стеклянных кнопок, их изображения, иконки и пропорции не заменяются.

## Что изменено

- Контроллер `plux-motion-v124.js` управляет оригинальными пятью MP4 без лишних перезапусков. Два видеослоя только на видимом экране, короткий crossfade, отбрасывание устаревших запросов, безопасное возобновление после скрытия вкладки, скорость 1×, без тяжелых полноэкранных фильтров.
- Экран знакомства: скрипт `onboard-cinematic-v116.js` стартует, только когда знакомство действительно отображается; текст печатается последовательно и не блокирует ввод имени. Тихие звуки вводятся только после разрешённого браузером пользовательского действия.
- Главная: `plux-typewriter-v124.js` печатает короткое личное приветствие один раз при входе; подзаголовок плавно проявляется. Старые сообщения не перепечатываются; новые сообщения PLUX могут появляться с эффектом печати.
- Лёгкие реакции стеклянных кнопок на касание, без дополнительных белых рамок, с уважением `prefers-reduced-motion`.

**Все 5 исходных видео сохранены без изменений.** Новые рендеры или модели Three.js их не подменяют.

## Запуск

Распакуйте архив и откройте каталог `public` через обычный локальный статический сервер:

```bash
cd public
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для Android используйте HTTPS-хостинг, например Render Static Site. `file://` может блокировать ES-модули и воспроизведение видео. Серверные API голоса и генерации из статического сайта не появятся автоматически.

## Проверки

- Автономный Chromium: компоновка, переходы, включение/снятие подсветки и печать текста на 360×780, 393×852, 412×915.
- 20 подряд запросов состояния `idle` = один видеопереход, а не 20 перезагрузок.
- В последовательности `listening → thinking → talking → thinking → happy → idle` итоговое состояние соответствует последнему запросу, без ошибок JavaScript.
- В локальных тестах отсутствуют ошибки JavaScript и отсутствуют запросы отсутствующих файлов.
- **Не проверено:** фактическая плавность и энергопотребление на Samsung. Стыки внутри исходных MP4 не идеально совпадают по кадрам; программный crossfade между эмоциями не устраняет сам исходный loop-seam.

## Важно

`GSAP` и навыки Three.js используются как инструкции по качественной анимации. В V12.4 **не добавляли тяжёлую зависимость GSAP**, потому что для данных эффектов достаточно CSS-анимации и нативного JavaScript. Это сохраняет низкую нагрузку на Android.
