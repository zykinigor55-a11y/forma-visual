### Что внутри проекта
Десять исходных PNG, карты глубины, прозрачные слои свечения, код рендера `render_v4.py`, скрипт финализации `finish_v4.sh`, саундмикс голоса и музыки *The First Thought*.

### GitHub-публикация видео
У подключённого GitHub API нет операции отправки локальных бинарных файлов и загрузки Release assets, поэтому **этот коммит сохраняет документацию и контрольные данные, но не сам MP4**. После загрузки бинарных файлов добавить релиз `serial-pro-bogov-ep04-v4`.

[Создать релиз на ветке serial-pro-bogov](https://github.com/zykinigor55-a11y/forma-visual/releases/new?target=serial-pro-bogov)

Выбрать тег `serial-pro-bogov-ep04-v4`, прикрепить Full HD MP4, мобильный MP4 и ZIP проекта.
