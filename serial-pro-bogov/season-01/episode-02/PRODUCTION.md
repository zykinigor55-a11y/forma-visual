# Производственные заметки — EP02

Использованы десять изображений из набора второй серии. Оригиналы хранятся вне GitHub в монтажной среде; исходное изображение нельзя считать нативным 2K только по размеру файла.

**Звук.** Исходный MP3 содержит неверную длительность в заголовках: ffprobe сообщает 113,535 с, но фактический декодируемый сигнал — 100,656 с. Для монтажа использована восстановленная PCM-дорожка; голос не ускорен и не обрезан. Музыка `The First Thought` — из первой серии, с компрессией sidechain по речи и затуханием перед финальной репликой.

**Визуал.** Все сцены ориентированы вертикально и анимированы процедурно:
- геометрическая камера с мягким параллаксом;
- временные ленты, движущиеся в противоположных направлениях;
- преломление пространства через смещение пикселей;
- световые импульсы, расширяющиеся дуги;
- эволюция звезды и световая волна;
- выбор возможных будущих через разветвлённые траектории;
- остановка движения и тёмное завершение.

**Характеристики:** исходная анимация — 576×1024, 24 к/с; экспорт Full HD (1080×1920) выполнен увеличением Lanczos, без заявления о нативном 1080p рендере. Финальный кадр постепенно уходит в чёрный.

**GitHub:** для полноценного сохранения самого фильма следует загрузить `DO_SOTVORENIYA_EP02_VERTICAL_FULLHD.mp4` как бинарный GitHub Release asset либо через Git LFS. GitHub-подключение данного сеанса умеет создавать и изменять текстовые файлы, но не переносит готовые бинарные файлы из локального монтажа непосредственно в репозиторий.
