# Эпизод 05 — финальная версия Premium V5 «Текущая энергия»

**Название:** «Наблюдатель извне» · **длительность:** 190 секунд · **кадровая частота:** 24 fps · **количество кадров:** 4560.

## Результат
Собраны полный мастер, версия Full HD и компактный MP4 для телефона. Их названия и SHA-256 приведены ниже. Все файлы физически созданы и проверены в рабочей монтажной среде. **В GitHub сохранены исходный исполняемый Python-рендерер, ТЗ, параметры экспорта и манифест; большие PNG, MP3, ZIP и MP4 пока не перенесены в GitHub через текущее подключение.**

## Технология
[Полный код рендера](render_v5.py) · [Утверждённое ТЗ](V5_PREMIUM_LIGHT_PLAN.md)

- Источники: десять отдельных PNG 941×1672; в исходном коде ожидаются в `/mnt/data/DO_SOTVORENIYA_EP05_10_IMAGES`.
- Камера: в каждой сцене одна плавная кривая движения; без резких смен планов.
- Золотые/голубые энергетические жилы: HSV + локальный контраст, очистка маски, скелетизация, поиск связных участков, расчёт геодезического расстояния и движение импульса вдоль существующей кривой. Это не произвольные новые нарисованные линии.
- Микроразряды: короткое усиление на уже существующих светящихся сегментах, примерно 2–4 кадра.
- Атмосфера: сдержанная холодная туманность в тенях, около 90 малых частиц на сцену.
- Нет дополнительных «3D-стеклянных пластин», искусственного искривления объектов и случайных зумов.
- Рендер: Python/OpenCV, NumPy, SciPy, scikit-image, FFmpeg (H.264/AAC).
- Озвучка `audio (7).mp3` без изменения скорости; прежний аудиомикс с музыкой *The First Thought*.
- Картинка V5 900×1600 из исходных PNG; отдельный экспорт 1080×1920 — апскейл, а не новые нативные детали.

## Восстановление и сборка
1. Распаковать проект: `render_v5.py`, `README_V5.md`, `audio (7).mp3`, `The First Thought.mp3`, каталог `frames/` с десятью PNG. Переместить `frames/` на путь, указанный в `render_v5.py`, либо исправить `ROOT`/`FILES`.
2. Установить зависимости: `python -m pip install numpy opencv-python scipy scikit-image`. Установить системный FFmpeg.
3. Выполнить `python render_v5.py` для создания видео без звука. Результат `EP05_V5_VIDEO_ONLY_900x1600.mp4`.
4. Добавить звук из ранее утверждённого мастера V4 без пережатия голоса: `ffmpeg -i EP05_V5_VIDEO_ONLY_900x1600.mp4 -i V4_MASTER.mp4 -map 0:v:0 -map 1:a:0 -c:v copy -c:a copy -t 190 FINAL_MASTER.mp4`.
5. Создать Full HD: `ffmpeg -i FINAL_MASTER.mp4 -vf scale=1080:1920:flags=lanczos -c:v libx264 -preset veryfast -crf 21 -c:a copy FULLHD.mp4`.
