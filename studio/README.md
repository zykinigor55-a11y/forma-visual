# FORMA STUDIO / Architectural Intelligence

Первая рабочая версия независимой веб-студии для архитектурного арт-дирекшна: фотография проекта → аналитика → поиск по профессиональным источникам → три варианта света → точный промпт для Nano Banana.

## Реализовано

- Загрузка JPG / PNG / WebP до 8 МБ, drag & drop, мобильная адаптация.
- Отдельные описания архитектуры, фасадов и задач; строгая фиксация геометрии, окон, кровли и ракурса.
- При наличии `VISION_API_KEY` — реальный визуальный анализ изображения через OpenAI-совместимый Chat Completions API.
- При наличии `BRAVE_SEARCH_API_KEY` — поиск ссылок на изображения на Behance, Divisare, ArchDaily, CGconnect, Dezeen через Brave Image Search. Источник каждого изображения и ссылка на оригинальную страницу сохраняются.
- Без API-ключей интерфейс работает как бриф-конструктор: **не выдаёт описания пользователя за AI-анализ** и предлагает поисковые ссылки вместо вымышленных результатов.
- Три фотографических направления: Editorial Daylight, Cinematic Blue Hour, Atmospheric Soft Light.
- Готовый подробный англоязычный промпт для image-to-image Nano Banana, копирование и скачивание `.txt`.
- Без зависимостей в продакшене; Node.js 20+, доступно для размещения на Render как Web Service.

## Запуск

```bash
cd forma-studio-v1
node server.mjs
```

Откройте http://localhost:3000 . Для запуска не нужен `npm install`.

## Подключение реального поиска и AI

Скопируйте `.env.example` в `.env` или добавьте переменные в панели вашего хостинга. Node не загружает `.env` автоматически — используйте экспорт переменных в shell, менеджер переменных хостинга или `node --env-file=.env server.mjs` (Node 20.6+).

| Переменная | Назначение |
|---|---|
| `BRAVE_SEARCH_API_KEY` | Ключ Brave Image Search API |
| `VISION_API_KEY` | Ключ совместимого мультимодального AI-провайдера |
| `VISION_API_BASE` | Адрес совместимого Chat Completions API, без `/chat/completions` |
| `VISION_MODEL` | Название поддерживающей изображения модели |
| `PORT` | Порт сервера, по умолчанию 3000 |

Выбирайте AI-провайдера, который принимает Chat Completions с content parts `image_url`/`text`. Некоторые агрегаторы используют другие форматы — для них понадобится адаптер.

**Важно:** API-ключи серверные; не вставляйте их в браузер или код фронтенда. Установите лимиты/квоты в кабинете провайдера.

## Render deployment

Это Node Web Service, а **не Static Site**, потому что поиск изображений и анализ защищены сервером.

- **Runtime**: Node
- **Root directory**: `studio` (если проект добавлен как папка `studio` внутри другого репозитория)
- **Build**: `npm run check`
- **Start**: `npm start`
- **Plan**: любой совместимый с Node (включая free при доступности)
- **Region**: Frankfurt для Европы
- **Environment**: переменные из таблицы выше, при необходимости

Если Root directory нельзя указать через интеграцию, укажите `cd studio && npm run check` и `cd studio && npm start` для Build/Start.

## Честные ограничения MVP

- Настоящий автоматический визуальный анализ требует настроенного ключа AI. Без него работают бриф, направления, поисковые ссылки и промпты.
- Автоматический поиск требует ключа Brave. При его отсутствии используются внешние поисковые ссылки по каждому домену.
- Референсы пока сортируются по источнику и релевантности поисковой выдачи; **компьютерное сравнение изображения здания с каждой найденной фотографией, авторское оценивание и генерация изображения через API Market ещё не подключены**.
- Генерация изображения в самой студии отсутствует: пока формируется промпт для внешней Nano Banana.
- Качество будущего изображения и фактическое разрешение 4K зависят от выбранной модели и параметров генерации.
- Работы на внешних сайтах не принадлежат студии; приложение отображает только превью поисковика и ведёт на оригинальную публикацию. Проверяйте авторские права на дальнейшее использование.

## API

- `GET /api/health` — доступность приложения.
- `GET /api/config` — только статусы подключений, без ключей.
- `POST /api/analyze` — `{image: dataURL, project: {type,materials,description,lockGeometry:true}}`.
- `GET /api/references?q=...` — пять источников, превью и страницы первоисточников.

Данные загружаемых изображений не сохраняются на сервере в этой версии. При подключении внешней AI-модели фото отправляется выбранному провайдеру для анализа.
