# PERSONA STUDIO — версия 0.3

Профессиональный конструктор цифровых персонажей с плавными шкалами, локальной библиотекой и опциональным защищённым API для фотореалистичной AI-генерации.

## Что уже работает

- Параметрическая 2D-модель с изменяемыми возрастом, ростом, комплекцией, тоном кожи, чертами лица, волосами и зубами.
- Отдельная настройка национальности и культурного происхождения без автоматических внешних стереотипов.
- Загрузка фото человека и снимков одежды; детали кистью на отдельном слое.
- Сохранение эталонных параметров, библиотека персонажей в браузере, экспорт PNG и паспорта JSON.
- Новый раздел **AI-генерация**: готов серверный модуль для создания фото по характеристикам; может использовать исходную фотографию человека, последний AI-результат и выбранное фото одежды как референсы.
- Настройки качества, формата, дополнительного запроса; хранение сгенерированных изображений в IndexedDB браузера (если доступно).
- Защитный код доступа к AI, ограничение числа генераций на сервере, валидация изображений и закрытые переменные окружения.

## Изменения в 0.3

- Отдельные AI-режимы: создать с нуля, сохранить идентичность, сменить только причёску, переодеть, нанести детали кожи.
- Можно загрузить фото причёски как дополнительный референс (не копирует лицо модели).
- Фиксация персонажа сохраняет снимок лица отдельно от текущего AI-результата в IndexedDB, не только бегунки.
- После генерации доступен предыдущий снимок для визуального сравнения.
- Примечание: это **не автоматическая проверка сходства лица** и **не пиксельное маскирование**. AI-результат нужно проверять вручную.

## Что пока не реализовано

- **В живом приложении AI не начнёт генерировать фото, пока владелец сервера не добавит действующий API-ключ и код доступа.** В этой поставке ключей нет, платных запросов не выполнялось.
- Гарантия точной идентичности лица, отдельные маски для точечных AI-правок, фотореалистичная 3D-геометрия.
- Настоящая примерка с физически корректной посадкой одежды, 360°-реконструкция и GLB/FBX.
- Многопользовательская авторизация и синхронизация через облако (сейчас файлы локальные).

## Локальный запуск

Требуется Node.js 20+.

```bash
npm start
```

Откройте `http://localhost:3000`. Без ключей приложение работает как редактор эскиза. Для запуска тестов:

```bash
npm test
```

## Включение AI (только на сервере)

Создайте серверные переменные окружения (например, в панели Render):

```
OPENAI_API_KEY=ваш_ключ_API
PERSONA_ACCESS_CODE=длинный_личный_код_доступа
OPENAI_IMAGE_MODEL=gpt-image-2
```

**Никогда не вставляйте ключ OpenAI в JavaScript сайта, HTML или GitHub.** После добавления переменных перезапустите сервер. Откройте вкладку `AI-генерация` и введите свой персональный код доступа. Код остаётся в памяти текущей страницы, API-ключ в браузер не передаётся.

Сервер использует официальный Images API — `POST /v1/images/generations` или `POST /v1/images/edits` при наличии референсного изображения. Для модели может требоваться проверка организации. Параметры качества и размера влияют на стоимость.

Для общедоступного коммерческого сервиса нужны отдельные аккаунты, серверная авторизация, лимиты на пользователя, учёт расходов, согласия на использование фотографий и надёжное хранение исходников. Текущий прототип рассчитан на ограниченное тестирование владельцем.

## Публикация на Render

В отдельном GitHub-репозитории можно использовать `render.yaml` как Blueprint или создать **Web Service**, не Static Site:

- Runtime: Node
- Build Command: `echo ready`
- Start Command: `npm start`
- Environment: переменные выше, вводятся вручную в Render

Если репозиторий содержит проект во вложенной папке, установите `Root Directory` на `persona-studio`. Ветка `persona-studio-dev` в существующем репозитории используется только как временная независимая копия проекта; основной сайт остаётся на `main`.

## Ограничения приватности

Собственные фотографии хранятся в браузере до отправки на AI. При нажатии генерации выбранные изображения передаются вашему серверу и затем поставщику AI-модели. JSON-паспорт не содержит фото. API-сервер не сохраняет входные изображения в постоянных файлах. Рекомендуется загружать только фотографии, на использование которых есть разрешение.
