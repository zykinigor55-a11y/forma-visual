# PERSONA STUDIO / Интерактивный прототип v0.1

Первая рабочая локальная версия конструктора цифровых персонажей. Цель — проверить интерфейс и данные до подключения платных AI-моделей.

## Как запустить

Откройте `index.html` в современном браузере. Можно также запустить простой локальный сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080/`.

Установка библиотек, API-ключи и серверная база данных пока не нужны. Есть также самостоятельный файл `PERSONA_STUDIO_preview.html` в отдельной поставке — он уже содержит стили и скрипты.

## Что уже работает

- Бегунки возраста, роста, комплекции, мускулатуры, тона кожи, параметров лица.
- Национальность / происхождение отдельно от особенностей внешности; поле для смешанного происхождения.
- Причёски, длина, густота, цвет волос, седина.
- Эскизный редактор зубов и улыбки.
- Мгновенное изменение **векторного 2D-эскиза** (не настоящая фотография и не 3D).
- Загрузка фотографии человека с сохранением в текущем браузере.
- Кисть-маркер для шрамов, родинок, веснушек, акне, морщин и пятен.
- Локальная библиотека персонажей и фиксация эталонных параметров.
- Загрузка фотографий одежды как референсов в гардероб.
- Четыре параметрических варианта эскиза, экспорт PNG / паспорта JSON.
- Адаптация для телефона.

## Чего пока нет

- Нейрогенерации фотореалистичных людей и устойчивой внешности на разных изображениях.
- AI-изменения загруженного лица при движении бегунков.
- AI-переноса загруженной одежды на человека.
- Реального 3D, новых фотографических ракурсов и детального моделирования зубов.
- Облачной синхронизации, авторизации и онлайн-сохранения.

## Безопасность и сохранение

Исходные фотографии сжимаются для хранения в браузере; в облако они не отправляются. JSON-паспорт **не содержит фотографий**. Хранилище браузера ограничено — сохраняйте PNG и JSON отдельно. Загружайте изображения реальных людей с их разрешения.

Ключи API **нельзя** вставлять в HTML или JavaScript фронтенда. Следующий этап: защищённый серверный API, Supabase Auth/Postgres/Storage с RLS, интеграция AI-изображений, версионирование, обработка масок и проверка постоянства внешности.

## Публикация на Render

После загрузки этих файлов в **новый отдельный** GitHub-репозиторий создайте Static Site в Render: `Build Command` = `echo ready`, `Publish directory` = `.`. Либо импортируйте прилагаемый `render.yaml`.

Ни один существующий сайт или GitHub-репозиторий не изменён.
