# ДОМ.РЕНДЕР — Nano Banana 2.1 (API Market)

Это **работающее локальное веб-приложение с серверной интеграцией API Market**, а не просто HTML-макет. Исходный SketchUp-подобный вид слева, демо-фотография справа, ползунок, каталог сезонов/погоды/зелени и локальный редактор масок сохранены из согласованного варианта.

## Запуск

Требуется **Node.js 20+**. Зависимостей npm нет.

1. Скопируйте `.env.example` в `.env`.
2. Создайте **новый API-ключ** в API Market и вставьте его только в `.env`: `API_MARKET_KEY=...`.
3. В папке приложения выполните `node server.mjs`.
4. Откройте **http://127.0.0.1:3000** в Chrome, Safari или другом браузере.
5. Загрузите собственный JPG/PNG/WebP с изображением дома, выберите настройки, нажмите **«Создать визуализацию»**.

> Ключ, который уже был опубликован в чате, считается скомпрометированным. Отзовите его и используйте новый. Не добавляйте `.env` в ZIP, GitHub или клиентский JavaScript.

## Что сделано

- `POST /api/render`: прокси на `https://api-market1.shop/v1/images/edits` с моделью `nano-banana-2.1`, `quality=high` и `response_format=b64_json`.
- Исходный скриншот — главный и обязательный референс; промпт строится из настроек и требует не менять геометрию и ракурс.
- Можно передать до трёх дополнительных референсов: материал, прошлый ракурс и PNG-маску выделенной поверхности (через совместимый `image[]`). Не все провайдеры гарантируют точность маски.
- Поддержаны ответы в base64 и HTTPS URL; результат скачивается сервером с ограничениями формата и адресов.
- При выборе двух или четырёх вариантов отправляются отдельные платные запросы по одному изображению, чтобы не полагаться на поддержку `n>1`.
- Ключ не возвращается браузеру; в ответе только данные изображения и безопасные диагностические сообщения.
- Сохранены загрузка проектов, собственные материалы и настройки, сравнение «до / после», адаптивный интерфейс и сохранение в браузере.

## Безопасность и публикация

Это **MVP для частного теста**, а не готовый публичный SaaS. По умолчанию сервер доступен только с компьютера (`HOST=127.0.0.1`). Для облачного хостинга (Railway/Render/свой VPS) задайте `HOST=0.0.0.0` и обязательно `SITE_ACCESS_PIN` — пользователям понадобится ввести код для генерации. Доступ защищён сессионным HttpOnly cookie и ограниченными попытками ввода. Сервер имеет дневной счётчик генераций (`DAILY_GENERATION_LIMIT`), но счётчик хранится только в памяти и обнуляется при перезапуске, поэтому **не заменяет долговременный биллинг и квоты**. Для платного запуска нужны аккаунты, очередь, постоянная БД, лимиты на пользователя, система оплаты и продуманная обработка тайм-аутов.

Статическая публикация только `index.html` в Netlify **не запустит AI**. Требуется Node.js-сервер, доступный через HTTPS. Защитите `.env`; не включайте его в `public` или раздачу статики.

## Ограничения API

API Market публикует модель `nano-banana-2.1` и редактирование через `/v1/images/edits`, но **живой платный вызов не тестировался**: у нас не было безопасно настроенного нового ключа в серверном окружении. Дополнительные референсы `image[]` и семантика маски могут требовать адаптации к фактическому поведению поставщика. Даже успешная AI-генерация не гарантирует идеальное сохранение фасада, геометрии и окружения между ракурсами без 3D. Скриншоты проекта передаются стороннему провайдеру — учитывайте конфиденциальность заказов.
