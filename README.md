# ДОМ.РЕНДЕР — готовый проект для Render (версия 2.5)

Архив содержит **действующее веб-приложение** с Node.js API, интерфейсом сравнения «До / После», редактором материалов, сохранением проектов и фотографическими пресетами. Исключены файлы постороннего Next.js-приложения из исходного большого репозитория.

## Запуск локально
1. Установите Node.js 22 или новее.
2. Скопируйте `.env.example` в `.env` и заполните `SITE_ACCESS_PIN` и `API_MARKET_KEY`. Не публикуйте `.env`.
3. Запустите `npm start`. По умолчанию откройте `http://127.0.0.1:3000`.

## Публикация в Render
Подключите этот GitHub-репозиторий, ветку `dom-render-deploy-ready` и выберите **Web Service**. Для Render настройки уже указаны в `render.yaml`:
- Runtime: Node 22
- Build Command: `echo 'No build step required'`
- Start Command: `node server.mjs`
- Health Check: `/api/status`

В разделе **Environment** добавьте `API_MARKET_KEY` (секрет вашего провайдера генераций) и `SITE_ACCESS_PIN` (защита публичного API). Значения ключей в архив не включены. `HOST=0.0.0.0` нужен только для сервера Render; локально используйте `127.0.0.1`.

## Дизайн и поддерживаемые экраны
- UltraWide / 4K: ограничение ширины рабочей области, крупный просмотр и панель инструментов справа.
- Широкие и обычные мониторы: гибкая сетка с боковой панелью.
- Планшет: панель настроек под изображением.
- Телефон: полноширинный просмотр и нижнее меню.
- Фото «До» — утверждённая стилизованная модель SketchUp (не экспорт из SKP), фото «После» — одобренный синий час.
- Пресеты окружения, погоды и сезонов сохраняются локально как WebP-данные в `dom-render-unified-presets.js`, поэтому не требуют внешнего фотосервиса.
- Скрипт `dom-render-clean-sketchup-v3.js` содержит встроенный чистый вид модели.
- При публикации Render загружает свежие версии CSS и JS без прежнего кэша.

## Примечания
- AI-генерация доступна только при действующем ключе и разрешённом доступе.
- История проектов и пользовательские материалы могут храниться локально в браузере — сохраняйте результаты отдельно.
- При отсутствии реального исходного SKP файл «До» остаётся визуальной реконструкцией.
- Никогда не добавляйте реальные секреты в GitHub или ZIP.

## Проверка
Откройте проект «Резиденция 01» и убедитесь, что слева чистая модель, справа синий час. В разделе «Рендер» пресеты без дома; при запуске в браузере они отображаются из встроенного атласа.
