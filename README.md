Проморолик промышленного комплекса, анимационный сериал про Мишу и рекламные ролики ZYKINA ART обсуждались и разрабатывались отдельно. Подтверждённых самостоятельных папок с их исходными материалами в доступных репозиториях не найдено. **Не выдаём каталог за резервную копию этих проектов.**

## Как пользоваться

1. Открыть нужную папку в таблице.
2. Нажать «Исходники» для перехода в действующую ветку или отдельный репозиторий.
3. Новые исходники складывать **в существующую папку своего проекта**, не в корень `forma-visual/main`.
4. Для независимого деплоя сохранять привязку Render / MCHost к исходному репозиторию и ветке.

Каталог создан 18.11.2026. При появлении новых репозиториев и проектов его нужно дополнять.
