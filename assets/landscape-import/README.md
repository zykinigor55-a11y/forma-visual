# Загрузка новых 17 фотореалистичных карточек FORMA VISUAL

Добавьте сюда **ровно один файл** `forma_visual_17_realistic_plants.zip` в ветку `dom-render-nanobanana`.

GitHub Actions `FORMA — install 17 new plant photo cards` автоматически распакует и проверит 17 отдельных прозрачных PNG 1080×1080, обновит `assets/landscape-photo/`, заменит версию URL изображений для сброса кеша и сделает коммит.

Проверяются имена, 17 уникальных файлов, размер, альфа-канал и прозрачные углы. Исходные изображения внутри ZIP должны иметь имена `assets/landscape-photo/{species}.png`.

## Важная оговорка по качеству

Серия создана как новое AI-изображение отдельных крон, разделённое на 17 карточек. Итоговый файл каждой карточки имеет 1080×1080, но не является 1080px-нативным фото отдельного растения: исходный общий лист меньше. Не называть его 2K-фотографией или ботанически подтверждённым фото.

Если ZIP не загружен — остаются старые карточки. Одного добавления этого README/workflow недостаточно для замены изображений на сайте.
