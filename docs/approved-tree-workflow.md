# FORMA — утверждённые деревья

По утверждению пользователем модели:
1. Сохранить утверждённую версию геометрии без незапрошенных изменений.
2. Подключить её в основной каталог 3D, сохраняя приоритет явно импортированных пользователем моделей.
3. Сохранять возраст, размеры и вариант каждого дерева в проекте; дать возрастные кнопки, если модель поддерживает этапы роста.
4. Передавать в AI-рендер исходный кадр и характеристики фактически построенного дерева, включая версию, возраст, размеры, доступные параметры ствола, ветвей и листвы. В серверном промте фиксировать силуэт, положение, форму ветвей, плотность листвы, рисунок коры и сдержанную цветопередачу. Не разрешать замену дерева типовой моделью.
5. Проверять основной каталог и серверный промт, а затем фото-рендер на совпадение с исходным кадром. Публикация кода не считается подтверждением качества изображения.

## Утверждённые модели

- Дуб — в работе, не утверждён.
