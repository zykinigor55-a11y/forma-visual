# ФОРМА / Функциональный паритет с VizMaker 1:1

**Цель:** сохранить собственные логотип, графитовую стену, типографику и архитектурную UI-систему «ФОРМЫ» и независимо реализовать сопоставимые **рабочие функции**. Не копировать чужой код, закрытые модели, материалы и оформление.

**Проверено 14 ноября 2026:** публичная страница https://www.vizmaker.com/ и документация по Archicad/Revit. Перечень возможностей взят из разделов *One workflow. More creative range*, *Best-in-Class AI Engines*, *Create cinematic shots*, *Integrate Your Favorite Apps*.

## Правила реализации

1. **Никаких фиктивных результатов.** Если API не подключён, инструмент прямо показывает это и не выдаёт заглушку за результат.
2. **Контроль расходов.** Перед платной нодовой цепочкой показать число вызовов, проверить серверную квоту и запросить явное подтверждение.
3. **Геометрия.** Изображения обязаны ориентироваться на исходный CAD-скрин. Но AI может ошибаться: не заявлять математическую идентичность без геометрической проверки.
4. **Сохранение.** Промежуточный результат каждой выполненной ноды хранится локально, итог AI — в галерее проекта.
5. **Не затрагивать старый сайт.** Отдельная рабочая ветка `feature/forma-archviz-studio`, публичный предпросмотр `/forma-preview.html`. Старые `index.html` и `server.mjs` не заменяются до приёмки.
6. **Приватность.** Ключи API остаются на сервере; опубликованный предпросмотр не выполняет платные AI-запросы.

## Текущая реализованная вертикаль

- Исходный скетч пользователя → нода Экстерьер или Интерьер → Свет/сезоны → текстовая замена материала → локальное 4K → Экспорт.
- Результаты сохраняются за отдельными нодами, цепочка останавливается на неподдерживаемом типе, не вызывая AI.
- Если пользователь остановил AI в браузере, серверный поставщик может продолжить работу и списать средства — это объясняется заранее.
- Следующий функциональный барьер: полноценные API для 8K AI Upscale, Area Upscale, Image-to-3D и Video; затем CAD-плагины и серверный учёт пользователей.

**Статус:** полноценного функционального соответствия 1:1 пока НЕТ, пока не реализованы и не проверены все пункты матрицы. Этот файл — технический источник истины, чтобы не выдавать UI-заглушки за готовые возможности.
