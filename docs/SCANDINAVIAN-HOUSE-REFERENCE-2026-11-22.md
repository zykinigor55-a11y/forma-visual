# FORMA VISUAL / DOM.RENDER — скандинавский дом по трём референсам пользователя

Дата: 22 ноября 2026. Исходники — **три фотографии домов, переданные пользователем в чате**. Это ориентиры визуального проектирования, не готовые чертежи; физические размеры фото неизвестны. Не использовать фотографии как лицензированные текстуры.

## Что брать из каждого изображения

1. **Первый снимок — двухэтажный дом «Стройлюкс»**. Светлая/тёмная серая вертикальная деревянная облицовка, тёмные оконные рамы, сложная графитовая фальцевая кровля, снегозадержатели, воронки и стояки, приподнятая деревянная терраса на реальном основании. Его многоскатная сложная форма **не должна** самовольно заменять существующий отдельный дом в редакторе.
2. **Второй снимок — одноэтажный SCANDI**. Основной ориентир для существующего пресета `scandi`: простая вытянутая масса, двускатная фальцевая кровля, глубокие свесы, натурально-серый вертикальный планкен, крупные чёрные окна/раздвижные порталы, подшивка, открытые желоба, стояки на углах.
3. **Третий снимок — «Сканди ЭкоДом»**. Характер остеклённого фронтона с импостами и деревянная веранда, опоры/стойки, связь дома с террасой и садовой дорожкой. В текущем модуле перенесено только **фронтонное остекление** с настоящим отверстием и отдельная открытая поддержанная терраса; **крупную несущую галерею/крыльцо под общей крышей не копировать без согласования геометрии дома**.

## Принятый вид пресета `scandi`

- Вертикальная настоящая геометрия доски, без штукатурки; две оттеночные партии: основной серебристый `#7E8789`, акцент у входа графитовый `#42494D`.
- Номинально 94 мм шаг / 84 мм видимая ширина планки, глубина 21,5 мм, зазор 10 мм, зашивка на тёмной ветровлагозащите. Угол закрыт отдельным металлическим доборным профилем.
- PBR нормали и шероховатость древесины из локальных CC0 карт 1K, геометрия планок инстансированная. Форма дома, координаты участка, размеры и ротация остаются сохранёнными.
- Оконный цвет `#222A2D`, измеренный ПВХ профиль 76 мм как 3D-образ, три стеклянных листа и дистанционные рамки, отдельно откосы, уплотнения и наружный отлив с капельником за пределами доски. Это **визуальная конструкция**: не заменяет детальные теплотехнические спецификации стеклопакета.
- Габарит карниза от 0,5 до 0,72 м по размеру дома. Фальцевая графитовая кровля сохраняет исходные скаты, добавлены вальцовки края, ветровая доска, подшивка, желоб и водосточная труба.
- Снегозадержатели — два круглых элемента на ряд, крепление к фальцу, по обоим скатам; для длинного ската по два ряда. Это визуальная раскладка, не расчёт снеговой нагрузки.
- Остекление фронтона — **прошитый** проём, в нём реальная прозрачная многослойная конструкция; нельзя рисовать стекло поверх сплошной стены.
- Перед основным окном — деревянная терраса без перекрытия входных ступеней: стойки, опоры, обвязки, лаги, инстансированные доски. Переход к земле — 3 подъёма по 160 мм (две нижние ступени и настил на уровне +480 мм). У главного входа самостоятельная нормальная лестница и площадка.
- Никаких новых внешних тяжёлых GLB. Никаких замен существующих утверждённых моделей дерева, куста, дома; изменения только в scandi.
- При визуальном осмотре обязательно оценить: настоящие прозрачные окна, фасад без заполнения окон досками, отлив 52 мм за плоскость планкена, ровную фальцевую кровлю, снятие снегозадержателей с линии желоба, отсутствие просветов в соединении нижней стены и фронтона, ровную террасу без пересечения с крыльцом.

## Проверки и статус

- `tests/landscape-scandi-user-photo-reference.test.mjs` — геометрия фасадов, реальный фронтонный проём, две снеговые направляющие и терраса.
- `tests/landscape-scandi-construction.test.mjs` — детальные оконные узлы, кровельные доборы, входная группа.
- `tests/architecture-house-screenshot.mjs` + CI `architecture-house-screenshot.yml` — **настоящая** локальная Chromium/WebGL съёмка. Публикация скриншота не тождественна публикации деплоя Render.
- Фото сами по себе не дают расчёта снеговой нагрузки, вентиляционного зазора, сечений несущих элементов, водоотведения или теплотехники: для стройки нужен отдельный конструктивный проект.
