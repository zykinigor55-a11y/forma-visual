# FORMA · PLAN TO INTERIOR — продуктовая и техническая спецификация
Дата: 15 ноября 2026 г. · Статус: утверждаемая архитектура функции, **не реализованный 3D-движок**.

## Обязательный пользовательский сценарий
**2D-план → подтверждённая геометрия 3D → оформление интерьера и мебели → фиксированные камеры → фотореалистичные изображения → LIGHT STUDIO / переосвещение.**

Запрещено генерировать финальную интерьерную фотографию «как будто это точная 3D-модель» непосредственно из неразмеченного плана. Если модель реконструирована приблизительно, явно показывать допущения.

### Шаг 01. Загрузка и метрическая калибровка
- Входы: PNG, JPG, PDF-план, затем по возможности DWG/DXF/IFC через отдельный парсер.
- Определить масштаб **по размеру, заданному человеком**: известная стена/размерная цепочка, задаваемая двумя точками; никогда не выбирать миллиметры автоматически без подтверждения.
- Распознавать кандидаты на стены, проёмы, двери, окна, комнаты, внутренние перегородки с confidence. Неизвестное — отдельное состояние «проверьте».
- Рабочий холст 2D с редактируемыми стенами/проёмами и привязками, undo/redo и возможностью вручную обвести контуры.
- Обязательные параметры: высота помещений, толщина стен, отметка пола, отметка подоконника и высота окон. Отсутствующие данные подсветить как предположения.

### Шаг 02. Каноническая 3D-модель
- Использовать Three.js/WebGL для **реальной геометрии**, а не изображение-имитацию 3D.
- Геометрия: стены как сегменты с толщиной, вырезы проёмов, пол/потолок, плинтусы только по выбору.
- Двухпанельный редактор: план 2D + синхронная 3D-сцена. Выделение стены в одном виде выделяет её в другом.
- Проверки: замыкание комнат, пересечения стен, положение дверей, высота проёмов, ширина проходов, коллизии с предметами мебели.
- Никакой AI-реконструкции точного 3D из одного изображения без проверки пользователя.
- По каждому объекту хранить единицы измерения, положение в мире, ID, тип и исходные измерения.

### Шаг 03. Интерьер, мебель и материалы
- Стиль: contemporary luxury / warm modern / Japandi / минимализм / современная классика / Scandinavian / loft.
- Материалы по поверхностям: пол, стены, потолок, двери, текстиль, мебель, дерево, камень, металл, цвета; материал — объект в модели, а не только строка промпта.
- Мебель из проверяемого параметрического или GLB-каталога с реальными габаритами; операции размещения/вращения/замены, проверка проходов.
- Разные дизайн-варианты используют **одну архитектурную геометрию**; историю хранить как версии проекта.
- Настройки должны сохраняться в структурированном формате (например, geometry.json + design.json + assets).

### Шаг 04. Камеры → фото
- Пользователь размещает камеры в 3D; можно фиксировать высоту камеры, focal length / FOV, уклон перспективы, соотношение сторон.
- Перед AI-рендером зафиксировать ID версии 3D-модели, ID камеры, стиль и материалы, освещение и референс-кадр.
- Генерация фотореалистичной фотографии из 3D-превью с явным запретом менять окна, двери, планировку, положение мебели.
- Для высокой геометрической верности использовать depth, normal, segmentation / маски, если API это поддерживает. Обычный image-to-image **не гарантирует** точного 1:1.
- Сохранение нескольких кадров должно ссылаться на одну версию модели.

### Шаг 05. LIGHT STUDIO — общий для «Интерьер» и PLAN TO INTERIOR
- Отдельные группы: свет **из существующих окон**, потолочные источники, встроенные/локальные светильники, комбинированный сценарий.
- Направление дневного света относительно камеры/окна, высота, характер теней (мягкие/естественные/контрастные/кинематографичные), вечерние сценарии.
- В 3D-редакторе вычислять направление прямого света, затенение стен и окон и реальные источники через PBR-рендер. Для точного географического солнца нужны ориентация здания, дата, время и геолокация (не угадывать).
- После AI-фотографии: кнопка «Переосветить», новый результат получает тот же source/camera/design geometry version. Без изменения мебели, отделки, планировки.
- «Распознать освещение фото» — **отдельная будущая функция** на vision-модели/сегментации: оценка расположения окон/светильников, направление света, confidence, ручная коррекция. Нельзя выдавать ручное предположение за работающий AI-анализ.
- Отмена/повтор запроса должны прозрачно сообщать, может ли запрос продолжаться у провайдера.

## Безопасная последовательность поставки
1. **MVP геометрии:** загрузка 2D → метрическая калибровка → редактор векторных стен/окон → 3D-экструзия → сохранение.
2. **Интерьер:** каталог расстановки мебели, материалы, реальные размеры, версии.
3. **Камеры и фото:** фиксированные ракурсы, референс из 3D, AI-генерация и история.
4. **LIGHT STUDIO:** единый UI, реальный свет 3D, image-to-image relight.
5. **Vision-анализ света и авторазбор плана:** подключать только после подтверждённого серверного API и тестов на реальных планах.

## Критерии приёмки
- При изменении размеров стены 2D и 3D обновляются согласованно.
- Без проверенного масштаба кнопка финального точного 3D-проекта заблокирована.
- Камера/размещение мебели остаются неизменными при смене света, сезона, тона отделки.
- Все AI-кадры связаны с версией одной 3D-модели.
- В интерфейсе честно обозначены вероятностные 2D→3D допущения и ориентировочная стоимость AI.
- На мобильных реализована поэтапная схема, а не тесный 3-колоночный редактор.
