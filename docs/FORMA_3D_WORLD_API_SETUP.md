# ФОРМА · 3D-миры и реалистичная генерация

## Что уже работает без AI API

Открыть `/forma-world.html` из «Панели проекта → 3D-мир».

- Демонстрационный архитектурный участок с деревьями, поверхностями, ограждением, светом и собственным домом-заглушкой.
- Импорт **GLB** (до 120 МБ, текстуры желательно включить в файл).
- Свободный обзор и прогулка WASD / стрелками на телефоне; высота ходьбы ориентировочная, **физических коллизий пока нет**.
- Четыре пресета света, PBR-материалы Three.js r187, HDR-окружение из собственного файла `.hdr` (до 50 МБ).
- Кадры PNG и настоящий рендер размера **3840 × 2160** без масштабирования исходной модели.
- Ракурс сохраняется в браузере; файлы GLB/HDR браузер не загружает на наш сервер.
- Утверждённые логотип FA, название «ФОРМА», графит и тёплый оттенок шампанского остаются прежними.

Это **3D-визуализатор**, а не генератор пространства по одной картинке. Встроенный демонстрационный дом — условный. Реальный архитектурный проект должен начинаться с **исходной CAD-модели**, иначе 3D-геометрия будет приблизительной.

## Как экспортировать модель

1. В Revit, SketchUp, Archicad или Blender экспортировать модель в формат **glTF 2.0 GLB**. При необходимости использовать штатный/сторонний экспортёр для конкретной CAD-версии.
2. Сохранять метровый масштаб, координаты, окна, кровлю, мебель и геометрию как есть; включить PBR-текстуры.
3. Оптимизировать полигональную сетку для браузера. 120 МБ — предел загрузки, а не гарантия плавной работы. Большие модели стоит разбить или использовать LOD.
4. Открыть страницу «3D-мир», нажать «Загрузить 3D-модель», выбрать GLB. HDR-файл даёт более правдоподобные блики и отражения.

## AI-провайдеры — серверные адаптеры готовы, но выключены

Две **разные** операции:

- **Meshy Image-to-3D:** по фотографии объекта создаётся текстурированная 3D-модель, результат GLB. Это не точная CAD-модель здания. Официальная справка: https://docs.meshy.ai/en/api/image-to-3d . API: `POST https://api.meshy.ai/openapi/v1/image-to-3d`, `GET .../:id`.
- **World Labs Marble:** по тексту/фото создаёт исследуемое пространство; может возвращать Gaussian splat / собственные форматы, **не гарантирует обычный GLB и точную архитектуру**. Документация: https://docs.worldlabs.ai/api ; серверная схема `POST https://api.worldlabs.ai/marble/v1/worlds:generate`, `GET /operations/{id}`. Схема и модели могут обновляться — проверять перед оплатой.

Они не выполняют автоматическое смешивание AI-сцены с CAD-домом. Это следующий отдельный этап: регистрация систем координат, единиц измерения и совместимый визуализатор splat/mesh.

### Где позже подключить ключи

Создать **отдельный сервис Render** для новой ФОРМЫ (НЕ переиспользовать публичный предпросмотр старого сайта). Выбрать сервис → **Environment** → добавить **Secret / Environment Variables**:

| Переменная | Значение | Назначение |
|---|---|---|
| `FORMA_WORLD_AI_ENABLED` | `true` | Разрешить API-миры (по умолчанию выключены) |
| `FORMA_WORLD_ACCESS_TOKEN` | длинный приватный секрет 24+ символов | Гейт для платных AI-запросов; не класть в репозиторий |
| `MESHY_API_KEY` | ключ Meshy API | Платная генерация GLB по фото |
| `WLT_API_KEY` | ключ World Labs Developer API | Платная генерация миров |
| `FORMA_MESHY_MODEL` | `meshy-7.1` | Модель Meshy по проверенной документации |
| `FORMA_WORLDLABS_MODEL` | `marble-1.1` | Версия World Labs; проверить актуальное имя в кабинете |
| `FORMA_WORLD_DAILY_CAP` | `3` | Лимит созданий за день (на один экземпляр сервера) |

**Не** вводить ключи Meshy или World Labs на веб-странице, в JavaScript, GitHub и в переписке. Браузерная форма использует *отдельный приватный код доступа* и не сохраняет его. Публичная страница `/forma-preview.html` (старый Render) не включает платные API-запросы; старый `server.mjs` не изменяется.

### Когда включать коммерческую генерацию

Текущая приватная схема годится для закрытого администраторского тестирования. Прежде чем открывать сторонним пользователям — **обязательно** добавить пользователей и авторизацию, платежи/кредиты, серверную очередь, долговременное хранилище заданий, контроль расходов по каждому пользователю, webhooks и изоляцию проектов.

API-генерация асинхронная: пользователь должен проверять статус задачи. Закрытие вкладки **не отменяет** задачу и возможное списание кредита. Статусы и успешность этих интеграций **не проверены на реальных оплаченных ключах**, тесты используют подставные ответы.

## Фотореализм

Приоритетный точный рабочий процесс:

**Revit/Archicad/SketchUp → GLB → HDR/PBR-свет → интерактивный 3D-мир → сохранение ракурса → фотореалистичный рендер.**

Последний этап можно выполнять в Blender Cycles / Unreal Engine 5 либо через отдельный AI image-to-image endpoint с сохранением ракурса. AI может менять окна, пропорции, кровлю, и поэтому все результаты **обязательно проверяются** сравнением с исходной CAD-сценой. Рендер 3840×2160 в Three.js — это высокое разрешение, но **не** гарантия фотографического качества при низкополигональной модели.

- Очередь генерации в базе данных и отдельное хранение скачанных GLB/3D-миров.
- Серверный фоторендер выбранного ракурса и режим анимации камеры.
