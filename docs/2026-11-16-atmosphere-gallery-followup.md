# Атмосфера, текстовый ландшафт и просмотр результата

Изменения относятся к ветке dom-render-nanobanana и https://dom-render-nanobanana.onrender.com/. Настройки положения солнца не менялись.

## Атмосфера

Удалены конфликтующие требования «Color grade only» и «Do not add objects». Шесть настроений получили отдельные указания для света, пространственных планов и тональных переходов в пределах существующих погоды, сезона, времени суток и направления солнца. Добавлены выбор породы для краёв кадра и интенсивность зелени. Автоматический режим просит определить существующую породу и продолжить её, без нового леса, перекрытия дома и переноса участка. Если деревья не распознаются, новые не добавляются. Воздушная перспектива зависит от расстояния; нулевое значение запрещает дополнительную дымку. Интерьеры не получают наружных деревьев.

## Ландшафт

Новые запросы отправляют чистый исходный фрагмент, маску и чистый полный кадр для контекста. Скриншот схемы с вырезанными деревьями и таблица изображений растений не отправляются. В запросе названы точные породы, крона, основание и размеры в процентах. Изображения карточек используются только на холсте размещения. Сохранена обратная совместимость старого контракта запросов со схемами.

Убраны ручные поля области тени/отражения и пунктирный прямоугольник этой области. Внутренняя маска согласования с поверхностью остаётся автоматической; защищённые пиксели сохраняются локальной композицией. Свет, тени и отражения описаны физически в запросе и зависят от существующих поверхностей. Масштаб увеличен до 5000%, пропорции и точка основания сохраняются; большое дерево естественно обрезается рамкой.

## Галерея и готовый кадр

В шапке студии и рабочих окон размещена кнопка «Галерея». Каждый новый результат сохраняется в истории проекта для восстановления, но получает gallerySaved=false. Общая галерея показывает новые кадры только после явного выбора «Сохранить в галерею». Старые результаты без поля gallerySaved остаются видимыми.

Общий просмотр результата реализован нативным dialog над любым инструментом. Изображения всех путей app.js (экстерьер, интерьер, материалы, свет, варианты, пакет, сценарии, bridge ландшафта/атмосферы/макро/плана) ставятся в очередь для просмотра после завершения обработки. Каждый кадр серии получает свой выбор. Сохранение привязано к id полученного кадра и проекту, а не к активному результату на момент нажатия. Ошибка записи сохраняет возможность повторить. Выбор «Не сейчас» оставляет кадр в истории проекта. Завершение видео WAN и видео в сценариях также вызывает просмотр и предлагает сохранение файла в локальную галерею.

Проверки до публикации: npm test — 128/128, node --check для изменённых JavaScript, git diff --check. Новые проверки покрывают настройки атмосферы и пограничные режимы, запрос без скриншотов деревьев, масштаб 5000%, очередь результатов, отказ записи и выбор конкретного id при смене активного кадра.

Локальный браузерный предпросмотр недоступен: удалённый браузер вернул ERR_CONNECTION_REFUSED для локального сервера. Платная генерация новых промптов в этом этапе пока не запускалась. Тесты подтверждают формирование запроса и управление результатами; качество AI-изображения зависит от модели и исходника.
