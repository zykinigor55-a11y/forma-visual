# Forma Визуал

Build the approved ivory/olive desktop-program workspace as a responsive web application for architects who do not want to write AI prompts. Preserve the Forma wordmark; no architectural studio subtitle. Upload a house screenshot, choose materials, color, roof, environment, season and light; view source/result/comparison; save projects and variants; export images.

Use the supported Vinext/Sites runtime, ChatGPT identity, D1 user-owned records and R2 user-owned images. Use Google Gemini image editing server-side, with a server-built prompt and original image on every request. No API key is available: clearly mark sample renders and never fake generation. Billing will be in Russia, provider/account/prices not selected: show connection status, never fake purchases. Publish an owner-private review version. Public audience and paid launch remain separate decisions.

Alternatives considered: a Flow-hosted tool cannot supply the requested independent subscription product; a static mockup cannot securely call Google or store projects across devices. Full-stack web app is the selected implementation based on the user's explicit request to build the approved screens.

Constraints: Russian UI; simple controls; responsive mobile workspace; no secret in client code; strict owner authorization; image upload validation; atomic monthly quota reservations; failure refunds; demo examples remain distinct from user results; preserve geometry is a prompt requirement rather than a guarantee.
