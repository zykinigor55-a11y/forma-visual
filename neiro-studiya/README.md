# Нейро студия · FORMA AI

Премиальная AI-студия полного цикла: CGI/AI-видео, 3D, разработка сайтов, приложений и интеллектуальных систем.

## Главная страница V18 — Black Cinema (22 ноября 2026)
- **Quantum Kinetic V14**: утверждённое 8-секундное видео из исходных пользовательских кадров, титановая механика, светящееся ядро, оригинальное сердцебиение и звук. **Настоящий MP4 и постер загружены в GitHub**.
- **Möbius Kinetic V17**: второй экран заменён на две настоящие замкнутые ленты Мёбиуса из титана (полувиток 180°), со шлифовкой, креплениями, внутренней механикой, отдельными бегущими световыми каналами и чёрным фоном.
- Графитовый адаптивный интерфейс, мобильная версия, управление звуком, Creative / Development / Intelligence.
- Файлы готовой страницы: [web/index.html](web/index.html), [web/styles.css](web/styles.css), [web/site.js](web/site.js), [web/assets/neiro-studiya-v14.mp4](web/assets/neiro-studiya-v14.mp4).
- 3D спираль построена программно с Three.js, загружаемым из CDN; при отсутствии WebGL показывается статический SVG.

### Black Cinema V18
- Новый кинематографический первый экран с авторским изображением механической ленты Мёбиуса и фирменной типографикой FORMA AI.
- Шесть направлений: разработка приложений, 3D-модели по фотографиям, архитектурная визуализация, AI-видео, CGI и интерактивные миры.
- Три авторских проекта с пометкой «Концепт»: АХРОН, Купол над водой, БОГИ.
- Адаптивные карточки, меню и модальные окна; форма составляет бриф и копирует текст, без фиктивной отправки.
- Исходное видео V14 осталось в web/assets. Механический Möbius продолжает работать во второй сцене через Three.js.
- Резервная ветка перед редизайном: `neiro-studiya-v17-backup-20261122`.
