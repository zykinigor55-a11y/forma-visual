# Нейро студия / NEIRO STUDIO
Премиальная AI-студия полного цикла: AI-видео и дизайн, разработка мобильных и веб-приложений, 3D-визуализация, AI-агенты и автоматизация.

## FORMA AI — Quantum Kinetic
Фирменный объект для главной страницы — титановая сфера со светящимся квантовым ядром. Сцена статична относительно камеры, пять металлических лепестков независимо открываются и закрываются, световые импульсы проходят по процессору.

### Текущая редакция
- **V4**: более широкое раскрытие лепестков (углы примерно 13–21°, увеличенный ход направляющих);
- строго неподвижная камера, круглая сфера не обрезается;
- оригинальный синтезированный саунд-дизайн: сервоприводы, мягкие металлические защёлки, низкий гул энергетического ядра;
- 8 секунд, 1920×1080, 30 fps; бесшовное зацикливание.

### Структура
`docs/ANIMATION_SPEC.md` — кинематика, свет, звук и проверка.
`web/index.html` — браузерная оболочка для MP4.
`assets/` — зарезервировано под файлы видео, GLB и исходное изображение.

**Важно:** объёмные MP4, GLB и исходный Banana-кадр пока в локальном архиве проекта. Эта ветка хранит описание и веб-оболочку; медиабинарники необходимо загрузить отдельно, прежде чем сайт заработает в публичном GitHub Pages.

Исходное фото и сценарий анимации утверждены для проекта FORMA AI. Новую студию ведём отдельно от рабочей ветки DOM.RENDER.
