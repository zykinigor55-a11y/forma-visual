# Quantum Kinetic V6 — 22.11.2026

## Задача
Продолжаем поднимать качество анимации титаново-квантовой сферы для главной страницы «Нейро студия / FORMA AI».

## Исправления V5 → V6
- Убрана условная плоская подложка, которая появлялась при раскрытии пяти металлических лепестков.
- Воссоздана внутренняя подвижная механика: концентрические металлические кольца, рёбра, крепёж, зубчатый венец и приводные штоки.
- Сохранены исходные фотореалистичные текстуры металлической оболочки и геометрическая композиция центрального процессора.
- Более плавные и согласованные движения отдельных панелей, сохранён неподвижный ракурс камеры.
- Контролируемые световые потоки по исходным микросхемам, без неоновых пересветов.
- Оригинальные синтезированные 8-секундные звуковые эффекты: электромагнитный гул, сервоприводы, фиксаторы, работа ядра.
- Добавлены 3D-объекты механизма в редактируемую GLB-сцену (164 геометрических элемента, 22 канала анимации).

## Проверено в готовом MP4
- 1920×1080, 30 fps, 240 кадров, 8.000 с.
- H.264 + stereo AAC 48 kHz.
- Границы сферы на пике: x=536..1379, y=124..954 — кадрирование не нарушено.
- Пик звука: −6.3 dBFS; средняя громкость: −18.2 dBFS.
- Средняя разница между первым и последним кадрами: 1.36/255 (из-за видеокодека).
- Разница между началом и максимальным раскрытием: 33.23/255 в центре.
- Значительных резких скачков движения не обнаружено.

## Файлы
Полный архив V6: `Neiro_Studiya_Quantum_Kinetic_V6_Complete.zip`. Он предоставлен отдельно в рабочей сессии и содержит MP4, GLB, WAV, Python-скрипты, viewer.html, оригинальное изображение и QA-кадры.

**GitHub пока хранит только спецификации, исходные текстовые файлы и веб-каркас. MP4, GLB и WAV ещё не загружены в репозиторий.** Для публикации необходима отдельная загрузка медиаданных.

## Честная оценка
V6 визуально сильнее V5. Но это по-прежнему гибрид фото/2.5D/3D, а не физически точный рендер инженерной модели. Оценку 10/10 заявлять нельзя. Для финального высокого уровня потребуется полная high-poly модель невидимых поверхностей, настоящие PBR-материалы и трассировка лучей в Blender Cycles / аналоге.
