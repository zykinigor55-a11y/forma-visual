# NEIRO STUDIO — Quantum Kinetic V9 (22 ноября 2026)

## Изменение архитектуры против V8
- **Пять основных лепестков теперь представляют собой замкнутые объёмные 3D-оболочки** с фронтом, боковиной и настоящей задней поверхностью. Это устраняет критический недостаток V8: незамкнутые текстурные плоскости.
- Для каждого лепестка отдельные приводы, втулки и опорные детали. Дополнительные концентрические кольца для глубины механизма.
- Сохранена геометрия общего силуэта и утверждённая фотографическая фактура корпуса. Есть две GLB-сцены: с фото-слоем и PBR-only для шейдерной доработки.
- Анимация записана в glTF: 8 секунд, 69 каналов, независимое движение пяти оболочек и внутренних колец.
- Видеоверсия полностью отрендерена из анимированного GLB в VTK PBR с фиксированной камерой, вместо сдвига фото-слоёв.
- Аудио взято из утверждённого премиального микса V8 без изменений.

## Проверено
* 5/5 новых оболочек — watertight, с согласованными нормалями.
* 203 узла сцены, 69 анимационных каналов.
* MP4 1920×1080, 240 кадров, 30 fps, 8,000 с, H.264/AAC.
* Размер сферы на пике в пределах x=540..1355, y=147..932 — без обрезки.
* Разница начало-пик: 23,16/255, начало-конец: 0,62/255, среднее по ROI.
* Контрольные рендеры сделаны из реального анимированного GLB при 0, 2.8, 4, 7.75 секунды.

## Ограничения
- Это действительная твёрдая 3D-геометрия оболочек, но фотографические отражения фронтальных лепестков ещё остаются наложенной текстурой. 
- Центральная микроэлектроника остаётся текстурой, а не полностью смоделированным чипом.
- Визуализация сделана через VTK PBR с процедурным студийным окружением, а не Blender Cycles / ray tracing; Blender недоступен в окружении.
- До проверки уровня 10/10 требуется детализировать скрытые петли, геометрию центрального ядра и микрорельеф металла с полноценным path-tracing.
