# NEIRO STUDIO — Quantum Kinetic V10

## 22 ноября 2026 · Два независимых кинетических ротора

Утверждённая титановая оболочка с квантовым процессором сохранена. Внутри добавлены **два настоящих объёмных ротора**, а не плоские светящиеся кольца.

- Внешний ротор: +74° по часовой стрелке, запуск ~1,0 с, выход на пик ~4,1 с.
- Внутренний ротор: −53°, запуск ~1,4 с, пик ~4,35 с.
- На роторах есть физические зубцы, ступенчатые кольца, асимметричные титановые маркировочные пластины и металлические заклёпки, чтобы перемещение читалось визуально.
- Возврат обоих роторов плавный, начиная примерно с 5,1 с и до 7,75 с. Первый и последний кадры совпадают в пределах компрессии.
- Центральный процессор НЕ вращается; внешняя сфера НЕ вращается; камера зафиксирована.
- Пять внешних лепестков продолжают согласованно раскрываться и закрываться, каждый из них — замкнутый твёрдый 3D-объект.
- Оригинальная звуковая дорожка с двумя раздельными моторами, фиксаторами и фоном квантового ядра, 24-bit PCM WAV / 48 кГц; в видео AAC stereo.

## Ограничения

V10 даёт читаемую 3D-кинематику, но не является 10/10 по физической достоверности: лицевая фактура бронепластин сохранена фотографической проекцией; электроника ядра — в основном изображение; свет — VTK PBR, не Blender Cycles. Следующий художественный этап — детализация внутренних механических поверхностей, 3D-электроника, path-traced отражения.
