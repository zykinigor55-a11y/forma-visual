# FORMA AI · Нейро студия V18 — Black Cinema

Новая кинематографичная главная страница по утверждённому визуальному макету.
Направления: разработка приложений, 3D-модели по фото, архитектурная
визуализация, AI-видео, CGI и интерактивные миры.

Шоу-рил Quantum Kinetic V14 сохраняется в assets/neiro-studiya-v14.mp4.
Контактный канал пока не подключён: форма составляет и копирует бриф,
но не отправляет его на сервер.

Локальная проверка в Chromium: 1440 / 820 / 390 px, без горизонтального
переполнения, работают навигация и модальные окна. WebGL и реальная
публикация проверяются после деплоя.
