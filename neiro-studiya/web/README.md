# НЕЙРО СТУДИЯ — FORMA AI · сайт V17

## Готово
- На первом экране **реальный MP4 Quantum Kinetic V14** (8 секунд, 1920×1080, с оригинальным звуком), без генеративной замены дизайна.
- Кнопка «Звук» с явным пользовательским включением; автозапуск без звука, циклическое воспроизведение.
- Блок **Möbius Kinetic V17**: вместо прежней спирали — два подлинных замкнутых кольца Мёбиуса с полуповоротом ленты, титановой фактурой и крепежом, центральным механизмом, синей/янтарной энергией и чёрной сценой.
- Премиальный графитовый интерфейс, адаптация под мобильные экраны, три направления студии и навигация.
- На слабых устройствах или при отсутствии WebGL/Three.js показывается статичная SVG-версия спирали.
- Сохранено снижение анимации для `prefers-reduced-motion`.

- Описание изменений V17: [V17_MOBIUS_KINETIC.md](../docs/V17_MOBIUS_KINETIC.md).

## Локальный просмотр
Распакуй архив, открой терминал в папке сайта и запусти:

```
python3 -m http.server 8080
```

Затем открой http://localhost:8080 . Для интерактивной 3D-спирали требуется интернет: Three.js подключается из CDN. Видео находится локально в папке `assets`, интернет ему не нужен.

## Публикация
Для публичного GitHub Pages при необходимости включить: `Settings → Pages → Build and deployment → Source: GitHub Actions`. Создание отдельного сайта на Render не удалось из-за лимита 25 сервисов на текущем тарифе; существующие сервисы оставлены без изменений.

## Ограничения
Веб-страница визуально проверена в Chromium в статическом режиме на desktop и mobile, без горизонтального переполнения. Загрузка Three.js/WebGL и автопроигрывание видео в реальном публичном браузере пока не подтверждены; на месте предусмотрен fallback.
Реальный контактный канал для студии пользователь пока не указал — вымышленные email/мессенджеры не добавлялись.
