# FORMA Neural Render — экспериментальный адаптер (27.11.2026)

**Статус:** модуль интеграции, не включён в рабочую версию DOM.RENDER. Базовая ветка, доступная через GitHub, указывает на R90, а не на последнюю R169; поэтому существующие файлы не менялись. Нет обученной модели, GPU-теста или деплоя. Это не официальный NVIDIA DLSS 5.

## Подключение к актуальной версии
1. Перенести forma-neural-render.mjs в актуальную сборку. Подключить npm-пакет three-dlss-nr и совместимый Three.js r180+ через ту же модульную систему; зафиксировать проверенные версии в lockfile. Не смешивать независимые копии Three.js.
2. Использовать отдельный WebGPU-совместимый экземпляр сцены/камеры или проверить совместимость всех материалов и объектов текущей сцены. WebGL renderer не передаётся в нейросеть; базовая сцена может продолжать отображаться через WebGL. Подложка host должна иметь position:relative и содержать только viewport, а не панели интерфейса.
3. Предоставить законно лицензированный каталог обученной модели в формате NRModel (manifest.json + model/stages/*). Не извлекать веса NVIDIA из бинарников. Не включать synthetic weights для пользователей.
4. В меню «Рендер» создать опциональный пункт «FORMA Neural Render (эксперимент)», выключенный по умолчанию. Не менять WebGL, WebGPU, облачный AI Render, мобильное меню.

```js
import {createFormaNeuralRender} from './forma-neural-render.mjs';
const neural = createFormaNeuralRender({
  host: viewport,
  getScene: () => currentScene,
  getCamera: () => currentCamera,
  modelSource: licensedModelDirectory,
  authorizedModel: true, // только после проверки права использования и происхождения
  onStatus: ({state,detail}) => showNeuralStatus(state,detail)
});
// При нажатии пункта меню:
neural.enable();
// На каждом фактическом изменении кадра (камера, трансформация, ветер,
// солнце, объекты, изменение viewport) скрыть предыдущий результат:
neural.moving();
// После завершения изменений:
neural.stationary();
// При выключении/закрытии редактора:
neural.disable();
neural.dispose();
```

Не вызывать stationary на каждом кадре: ожидание 450 мс должно успевать завершиться. При непрерывной анимации ветра и воды предпочтительно отключать экспериментальный слой или явно ставить сцену на паузу. Не применять статический слой к живому видеопотоку. При отсутствии модели или WebGPU исходная сцена остаётся видимой. Порог разрешения по умолчанию 512x512 с сохранением пропорций, натуральный стиль и отдельный canvas с pointer-events:none. Не обещать сохранность геометрии на итоговом нейросетевом изображении: требуется визуальный контроль фасадов, текстур, окон и растительности.

## Проверки до релиза
- Без модели, WebGPU или HTTPS: отказ от запуска, без изменения базового кадра.
- Проверить на RTX 3050/3060 и других GPU, измерить задержку и память, оценить восстановление после потери GPU.
- Проверить движение WASD и мышью, редактирование деревьев, resize и отмену устаревшего кадра.
- Проверить цвета и сохранение геометрии, качество газона, отражений, стабильность GPU; сравнить с оригиналом.
- Проверить работу на мобильных без загрузки библиотеки/модели, отключение и освобождение ресурсов.
