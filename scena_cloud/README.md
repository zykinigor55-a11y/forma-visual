# СЦЕНА • облачный ИИ-сервер

Отдельная ветка **scena-cloud-20261112** в `forma-visual`. Существующие сайты и другие проекты не изменены.

Реализован API:
- `GET /api/health` — состояние и зависимости;
- `POST /api/process` — загрузка музыки с заголовком `Authorization: Bearer <личный токен>`;
- `GET /api/jobs/{id}` — статус и результат;
- `GET /api/files/{id}/{name}` — приватное скачивание результата;
- `DELETE /api/jobs/{id}` — удаление материалов.

Demucs разделяет вокал и инструментальную дорожку; Faster-Whisper распознаёт слова. Файлы временные, автоматическая очистка после обработки через два часа. Без `SCENA_ACCESS_TOKEN` обработка закрыта.

## Запуск на Render

Создать **новый** Web Service из репозитория `zykinigor55-a11y/forma-visual`:
- Branch: `scena-cloud-20261112`
- Runtime: Docker
- Dockerfile path: `./scena_cloud/Dockerfile`
- Docker context: `.`
- Secret environment variable: `SCENA_ACCESS_TOKEN` (минимум 32 случайных символа)
- Test: `/api/health`, затем выполнить обработку тестового трека.

### Ограничения
На 12.11.2026 Render отклонил создание: **Hobby Tier is limited to 25 services**. В My Workspace уже 25 сервисов, среди них 23 static_site и 2 web_service. Не удаляйте существующие сайты без согласования.

Кроме того, Render Free (512 МБ ОЗУ) для Demucs + Faster-Whisper недостаточен. Для действующей ИИ-обработки потребуется вычислительный тариф с памятью, достаточной для моделей. Платный тариф не подключён.

**Статус:** серверные исходники загружены, развернутого API пока нет. Бесплатное приложение для пользователей можно сохранить, но серверные расходы в будущем будут на стороне владельца.
