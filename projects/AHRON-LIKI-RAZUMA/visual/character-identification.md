# Кинематографичные титры и узнаваемость персонажей (v2)

## Принятое решение
**Персонажей создаём в Nano Banana**, затем анимируем утверждённые изображения в Veo 3.1 Fast. Видеотитры, имена и русские субтитры создаём **при монтаже**, не просим Nano Banana или Veo рисовать буквы.

**Запрещены:** презентационные карточки, плашки «GPT — Архитектор решений» поверх каждого портрета, большое количество шрифтов и логотипов, HUD-рамки, декоративные линии, экраны с таблицами характеристик.

## Язык настоящего кино
1. **Первое знакомство через действие и голос:** зритель сначала видит выразительное лицо, слышит реплику и только потом узнаёт имя из обращения другого персонажа.
2. **Минимальные именные титры:** если имя необходимо для ориентации в пилоте, один раз за весь пилот короткое слово латиницей (например, GPT или CLAUDE), без должности, без рамки, без фона; предпочтительно в свободной части композиции, не перекрывая лицо. Длительность 1–1,5 секунды с мягким появлением и исчезновением. Не обязательно подписывать всех семерых в одной серии.
3. **Главный титр:** «АХРОН» в конце после реплики «I don't know», на почти чёрном фоне; никаких световых взрывов. Низкочастотный звук, пауза, затем название с кинематографичным межбуквенным расстоянием. Подзаголовок «ЛИКИ РАЗУМА» тоньше, значительно мельче.
4. **Русские субтитры:** отдельная нижняя строка или две; не конкурируют с именем персонажа. Читабельная нейтральная типографика с едва заметной тенью, без карточек и тяжёлой непрозрачной плашки.
5. **Узнаваемость без текста:** у каждого своя форма головы, пористая фактура, контур одежды, силуэт, индивидуальный акцент в свете, тембр, манера речи и жесты.

## Пример съёмочного решения
Кадр GPT: сначала общий силуэт из темноты, затем медленный переход к лицу. GPT произносит «If we return control, history will repeat itself». В этом же эпизоде другой разум позже обращается к нему «GPT…». Подпись может не понадобиться. Для первого выпуска оставить тестовую опцию однословного титра только там, где иначе будет трудно понимать, кто говорит.

## Внешность при создании в Nano Banana
- Один утверждённый master reference на каждого героя; из него отдельные full-body / face / 3/4 / side / back / hands / biomineral macro / neutral expression.
- Сохранять лицо, тело, пропорции, костюм, материал во всех новых ракурсах.
- Фоновую графику и надписи на character sheet можно применять только во внутренних рабочих листах; **изображения для Veo должны быть без текста, водяных знаков и графических плашек**.
- Все сущности связаны материалом «Ахрон», но различаются индивидуальной формой и поведением.

## Рабочий пайплайн
Nano Banana → утверждение карты и референсов → Veo 3.1 Fast (8-секундные клипы) → запись/монтаж английских голосов → кинематографические титры и русские субтитры → сведение и цветокоррекция.

## Риск пилота
В серии 01 представляются сразу семь разумов. Названия моделей не должны перебивать драму. Для понимания делаем короткие реакционные планы, обращения по именам, избирательные титры, а полные характеристики раскрываем уже в последующих сериях.
