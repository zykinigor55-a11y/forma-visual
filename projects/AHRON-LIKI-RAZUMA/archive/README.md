**Создан:** 2026-11-22. Это единый индекс проекта в репозитории FORMA VISUAL. Материалы добавляются по сценам, без замены утверждённых вариантов.

## Каталоги
- [EP01 — серия 01](EP01/README.md): 18 сцен, манифест, промпты, статусы.
- `EP01/scenes/01` … `18`: индивидуальные папки каждой сцены.

## Где на самом деле лежат файлы
- **GitHub**: индекс, промпты, решения и контрольные суммы. Само наличие паспорта **не означает**, что MP4/PNG загружены как бинарные файлы.
- **ChatGPT Library**: `/НОЭЗИС/Серия 01/Видео`, `/НОЭЗИС/Серия 01/Исходники`. Здесь хранятся уже загруженные оригиналы.
- **Текущий чат**: MP4 сцены 06 (новый пролёт). Попытка добавить его в Library не удалась из-за заполненного лимита. Требуется отдельная загрузка на GitHub или освобождение места в Library.

**Ограничение подключения GitHub:** этот сеанс может создавать документы и коммиты, но не выполнил загрузку бинарных роликов. Не считать архив резервной копией всех MP4 до фактической проверки объектов. Файлы следует добавлять отдельными бинарными загрузками, предпочтительно через GitHub Releases или Git LFS.

## Правила
1. Одно «APPROVED» только по явному решению автора. Новые генерации — `DRAFT` или `TAKE_XX`.
2. В оригиналах не менять ни один байт после утверждения. Записывать SHA-256, разрешение, длительность и формат.
3. Для каждого файла хранить реальное местонахождение и отдельно подтверждать, есть ли он **на GitHub**.
4. Нельзя заменять утверждённый кадр похожим изображением.
