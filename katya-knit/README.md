# KATYA KNIT — видеоглавная + галерея

**Публикация:** https://katya-knit-art-gallery.onrender.com  
**Галерея:** https://katya-knit-art-gallery.onrender.com/catalog.html  
**Репозиторий:** zykinigor55-a11y/forma-visual, ветка `katya-vyazka`, подпроект `katya-knit/`.

## Утверждённая структура
- Главная `index.html`: **только полноэкранное видео**, логотип KATYA KNIT и большая кнопка **«ГАЛЕРЕЯ»** с переходом на `catalog.html`. Дополнительных разделов ниже видео нет.
- Мобильное видео: `assets/hero-mobile-final-loop.mp4`, десктоп: `assets/hero-living-canvas.mp4`.
- Логотип: **выбранный чёрно-белый графический знак из тонких линий** `assets/brand-ring-monochrome.svg` (белый на видео, тёмный в галерее). **Не подменять цветным кольцом**.
- Галерея `catalog.html`: светлая стена, медные рамы, отдельные произведения и полноэкранный просмотр.
- Изображения в галерее: `highres/KATYA_KNIT_01_Potok_4K.jpg` … `highres/KATYA_KNIT_10_Orbita_4K.jpg` — существующие в GitHub улучшенные версии вместо прежних крохотных `assets/art-XX.webp` по 38–67 КБ.
- `assets/video-only.css` — дизайн главной; `assets/exhibition.css` и `assets/exhibition.js` — галерея и модальный просмотр. Для мобильных устройств есть адаптация.
- В GitHub пока опубликованы **10 работ** из начальной серии; **семь новых авторских работ** существуют в отдельном готовом архиве и должны быть добавлены в репозиторий перед отображением в каталоге.

## Важное о качестве изображений
Существующие 4K JPG — в основном увеличенные исходники с улучшенной детализацией, **не прямые фотографии физически созданных произведений**. Не утверждать, что это полностью реконструированные изображения с новыми микроволокнами. Исходники сохранять без изменений.

## Обновление
Render автоматически публикует изменения в `katya-vyazka` с папкой публикации `katya-knit`. Не менять другие проекты и ветки.

## Фирменное оформление
Имя: KATYA KNIT. Слоган: **НИТЬ СТАВШАЯ ИСКУССТВОМ**. Шрифты: Prata для названия и Manrope для интерфейса. Без цветного логотипа и лишних блоков на главной.
