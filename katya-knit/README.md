# KATYA KNIT — арт-галерея, версия 7

Отдельный сайт KATYA KNIT в ветке `katya-vyazka` репозитория FORMA VISUAL. Основной сайт FORMA VISUAL не изменён.

## Быстрый старт
Открыть `katya-knit/index.html` через локальный HTTP-сервер (например, `python -m http.server 8000`, затем `http://localhost:8000/katya-knit/`). Важны соседние файлы `catalog.html` и папка `assets/`.

## Дизайн
- Первый экран как арт-инсталляция: почти полноэкранное макровидео с нитями; без огромного слогана поверх видео.
- Утверждённый **левый одноцветный знак из тонких нитяных линий** в шапке: `assets/brand-ring-monochrome.svg`.
- Призыв `СМОТРЕТЬ КОЛЛЕКЦИЮ` ведёт к пяти избранным работам. Справа на широком экране — вертикальная ссылка `ОТКРЫТЬ ГАЛЕРЕЮ`.
- В отдельном `catalog.html` — десять визуальных концепций произведений.
- Фирменный слоган: **«Нить ставшая искусством»**, без запятой и курсива. Название — Prata, вспомогательный текст — Manrope.
- Описание технологии изготовления не публикуется.

## Видео
- `assets/intro-ring.mp4` — видеозаставка с формированием кольца. Бренд и слоган выводятся отдельными HTML-слоями, чтобы избежать ошибок в буквах.
- `assets/hero-living-canvas.mp4` — горизонтальная петля для компьютера; прежняя версия, до передачи нового широкоформатного ролика.
- `assets/hero-mobile-final-loop.mp4` — веб-оптимизированное мобильное видео 1080×1920, 16,5 с, 30 fps, автоповтор без звука. Для экономии веса качество сжатия ниже оригинала.
- **Оригинальное видео** сохранено БЕЗ рекодирования в `masters/mobile-hero-1080x1920.mp4.part01` … `.part05` (сегменты двоичного файла).
- Для восстановления исходного MP4: `python katya-knit/restore_original_video.py` из корня репозитория. Проверочный SHA-256: `0fd50916c1867c40e5082a0db438234b68fb4bf1968581cf868e215922042ebc`.

## Изображения
- `assets/art-01.webp` … `assets/art-10.webp` — лёгкие оригинальные миниатюры для сайта.
- `highres/KATYA_KNIT_*_4K.jpg` — десять **отдельных увеличенных 4K-экспортов** с сохранением исходной композиции.
- **Важно:** эти 4K JPG пока являются улучшенными масштабированием исходниками, **не утверждённой AI-реконструкцией** рельефа, ворсинок и штукатурки. Новую AI-обработку пользователь запросил; её предстоит выполнить по каждому произведению с контролем изменений. Не выдавать их за фотографии реальных готовых изделий.
- `assets/hero-master-8k.webp` — веб-оптимизированный 8K фон для крупных экранов; оригинальный мастер доступен в рабочем архиве проекта.

## Статус
Это прототип: формы, контакты, товарные цены и публикация ещё не подключены. Не утверждать, что сайт уже развёрнут в интернете. Перед живым запуском подключить реальные контакты студии, заполнить карточки готовых работ и проверить права на изображения.
