# Wan 3.0 — Alibaba Cloud Model Studio (Singapore)

## Статус

Интеграция добавлена в существующий раздел **«Анимация»** приложения ДОМ.РЕНДЕР. Рендеры, проект, настройки камер, объективов и движения не менялись.

По умолчанию **генерация Wan 3.0 заблокирована** до настройки и безопасного включения пробной квоты владельцем.

## Пробная квота и риск списаний

Официальная документация Alibaba Cloud (ноябрь 2026):

- Только модель `wan3.0-video` (не `wan3.0-video-prime`), в регионе **Singapore**.
- Для подходящих новых аккаунтов — **30 секунд видео суммарно**, срок 90 дней; это НЕ ежедневное начисление и НЕ 10 видео в сутки.
- При исчерпании может автоматически включиться оплата по секундам.
- **В первую очередь обязательно включить Free Quota Only** для модели `wan3.0-video` в Alibaba Model Studio → Usage/Billing → Free Quota и убедиться, что статус активен. Если квоты/переключателя нет — НЕ запускать модель.
- Настройка Free Quota Only не действует мгновенно, прежде чем создавать первое видео убедитесь, что статус применился.
- Лимит сайта `WAN_DAILY_LIMIT=10` — только внутренняя защита. Он **не даёт 10 бесплатных роликов**. Он хранится в памяти и сбрасывается при перезапуске сервера Render.

## Настройка Alibaba и Render

1. Откройте https://modelstudio.console.alibabacloud.com и выберите **Singapore**.
2. Завершите регистрацию/активацию Model Studio, если потребуется.
3. Найдите модель **wan3.0-video**, проверьте её личный оставшийся пробный баланс. Перейдите на страницу **Free Quota**, включите **Free Quota Only** для именно этой модели. Убедитесь, что включение применилось.
4. Создайте API Key для этого региона и скопируйте Workspace ID своего workspace.
5. В Render → сервис `dom-render-nanobanana` → Environment добавьте:

```env
DASHSCOPE_API_KEY=<секрет Alibaba Cloud Singapore>
WAN3_WORKSPACE_ID=<точный Workspace ID Alibaba Cloud Singapore>
WAN3_ENABLED=true
WAN3_FREE_QUOTA_ONLY_CONFIRMED=true
WAN3_ACCESS_PIN=<придумайте случайный приватный код минимум из 12 символов>
WAN_DAILY_LIMIT=10
```

**Последний параметр CONFIRMED устанавливать только после реального включения Free Quota Only в кабинете Alibaba.** Значение не подтверждает и не меняет настройки в Alibaba автоматически. Ключ и приватный код никогда не отправлять в чат, GitHub или публичный JS.

## Алгоритм

- GET `/api/wan3/status` — показывает, почему модель ещё заблокирована, плюс внутренний лимит.
- POST `/api/wan3/generate` — JSON `{image, prompt, duration, ratio, accessPin}` (закрытый код WAN3_ACCESS_PIN). Отправляет Base64 первого кадра через официальный POST `/api/v1/services/aigc/video-generation/video-synthesis` региона Singapore, с заголовком `X-DashScope-Async: enable`.
- GET `/api/wan3/job?id=...` — опрос официального `GET /api/v1/tasks/{task_id}`.
- GET `/api/wan3/download?id=...` — потоковое скачивание mp4 с временного URL от Alibaba.
- Кадр, ключ и task ID не включаются в URL браузера (кроме непрогнозируемого локального id задачи). Пересылка кадра происходит сервер-сервер в формате Base64.
- Для первой проверки рекомендуется **5 секунд, 480P без аудио**. Параметры задаются сервером, не подделываются в браузере.

## Ограничения прототипа

- API-ключ и квота не могут быть проверены без настройки аккаунта Alibaba. Реальная генерация ещё не выполнялась.
- Анонимный сайт, без учётных записей. Запуск заблокирован без приватного **WAN3_ACCESS_PIN** (минимум 12 символов), который знает только владелец. Не сообщайте этот код посетителям. Перед публичной коммерческой генерацией нужны полноценные аккаунты и учёт платёжных расходов.
- Задания и лимит хранятся только в памяти Node. Перезапуск инстанса теряет историю. Видеоссылки Alibaba живут 24 часа.
- Внутренний дневной лимит — НЕ финансовый предохранитель. Обязательный финансовый предохранитель — **Free Quota Only на стороне Alibaba**.
- 480P — самый экономный тестовый режим. Повышение до 720/1080P следует делать только по отдельному запросу после тестов.
- В архитектурных анимациях окно/геометрия могут деформироваться даже при строгих ограничениях промпта. Обязательно проверяйте результат.
